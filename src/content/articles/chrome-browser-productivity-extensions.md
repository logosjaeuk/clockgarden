## 1. 당신의 브라우저는 지금 메모리를 얼마나 집어삼키고 있습니까?

일을 열심히 하는 사람일수록 웹 브라우저 상단에는 30개, 50개의 탭이 바늘구멍처럼 좁아진 채 열려 있습니다. "나중에 읽어야지", "이 자료 참고해야지"라며 닫지 못한 탭들은 컴퓨터 메모리(RAM)를 고갈시켜 전체 시스템을 버벅거리게 만들 뿐만 아니라, 사용자의 시각적 주의력을 끊임없이 분산시킵니다.

크롬(Chrome) 브라우저를 지저분한 정보 쓰레기통이 아니라, 강력하고 집중력 높은 업무 무기로 탈바꿈시켜 주는 핵심 확장 프로그램과 탭 관리 루틴을 정리합니다.

---

## 2. 탭 지옥에서 탈출하는 핵심 확장 프로그램 3선

### ① 원탭 (OneTab): 메모리 95% 절감과 탭 목록 보관
- 동작 방식: 클릭 한 번으로 현재 열려 있는 20~30개의 탭을 단 하나의 깔끔한 텍스트 링크 목록 페이지로 압축 변환합니다.
- 효과: 브라우저가 차지하던 수 기가바이트(GB)의 메모리가 즉시 확보되어 PC가 다시 날아갈 듯 빨라집니다. 필요할 때 언제든 링크를 클릭해 개별 또는 전체 복원할 수 있습니다.
- 실무 활용: 프로젝트별로 자료 조사를 마친 뒤 "A사 시장조사 탭 목록"처럼 이름을 붙여 웹페이지 링크로 팀원들에게 공유할 수도 있습니다.

### ② 크롬 기본 기능: '탭 그룹(Tab Groups)' 색상 라벨링
외부 프로그램 설치 없이도 크롬 자체 내장 기능인 **[탭 그룹]**을 활용하면 브라우저 상단이 몰라보게 단정해집니다:
- 탭 우클릭 ➔ **[새 그룹에 탭 추가]**
- 그룹 이름(예: `기획`, `개발`, `참고자료`)과 고유 색상을 지정합니다.
- 그룹 라벨을 클릭하면 해당 그룹의 탭들이 한 번에 접히면서 공간이 확보됩니다.

### ③ 비미움 (Vimium): 마우스 없이 키보드로 웹서핑
- 키보드의 `f` 키를 누르면 웹페이지 내의 모든 클릭 가능한 링크와 버튼 위에 노란색 알파벳 힌트가 뜹니다.
- 해당 알파벳 2글자를 키보드로 치면 마우스 커서를 움직이지 않고도 그 링크가 즉시 클릭됩니다.
- 익숙해지면 웹 서핑 속도가 일반 마우스 사용자의 3배 이상 빨라집니다.

## 3. 크롬 필수 단축키 치트시트

브라우저 조작 시간을 획기적으로 줄여주는 단축키입니다.

| 단축키 (Win / Mac) | 기능 설명 |
| :--- | :--- |
| `Ctrl/Cmd + T` | 새 탭 열기 |
| `Ctrl/Cmd + W` | 현재 탭 즉시 닫기 |
| `Ctrl/Cmd + Shift + T` | **방금 실수로 닫은 탭 복구** (최대 10개까지 역순 복원) |
| `Ctrl/Cmd + L` | 주소창으로 즉시 포커스 이동 (검색어 바로 입력) |
| `Ctrl/Cmd + 1 ~ 8` | 왼쪽에서 N번째 탭으로 번호 직행 |
| `Ctrl/Cmd + 9` | 맨 마지막 탭으로 순간 이동 |
| `Ctrl/Cmd + Tab` | 다음 탭으로 순차 이동 |

> [!NOTE]
> 특히 **`Ctrl/Cmd + Shift + T`**는 직장인 생존 단축키입니다. 장문의 글을 작성 중이거나 중요한 웹페이지를 실수로 닫았을 때 마우스로 방문 기록을 뒤질 필요 없이 단 0.1초 만에 그대로 부활시킵니다.

## 4. 퇴근 전 3분 '브라우저 제로(Browser Zero)' 루틴

메일함의 메일을 비우는 '인박스 제로'처럼, 브라우저에도 퇴근 전 정리 루틴이 필요합니다:

1. **오후 5시 50분:** 현재 열린 탭 중 오늘 완료된 일의 탭은 가차 없이 `Ctrl + W`로 닫습니다.
2. **내일도 봐야 하는 탭:** 3개 이내로 추려 핀(Pin) 고정(`탭 우클릭 ➔ 고정`)해 둡니다.
3. **나중에 읽을 자료:** 원탭(OneTab) 버튼을 눌러 목록에 보관하거나 노션 인박스로 넘깁니다.

내일 아침 출근했을 때 깔끔하게 비어 있는 단 하나의 홈 화면을 마주하는 쾌적함은, 하루의 업무 생산성을 결정짓는 최고의 시작점이 됩니다.
