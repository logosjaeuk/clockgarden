## 1. 서론: 밤하늘을 손목 위에 담다

손목시계 다이얼의 6시나 12시 방향에 뚫린 부채꼴 모양의 반원형 창 안에서, 짙은 남색 밤하늘과 금빛 별무리 사이로 천천히 얼굴을 내밀고 사라지는 작은 달. 시계 애호가들이 가장 사랑하는 감성적 컴플리케이션 중 하나인 **문페이즈(Moon Phase, 달의 위상 디스플레이)**입니다.

문페이즈는 고대 항해사들에게는 조수간만의 차를 예측하는 생명의 도구였고, 농경 사회에서는 파종과 수확을 결정하는 달력의 핵심이었습니다. 그러나 이 낭만적인 달 그림 뒤에는 정밀한 천문학 상수와 톱니바퀴 이빨 수의 기어비(Gear Ratio)를 둘러싼 치열한 수학적 최적화가 숨어 있습니다.

---

## 2. 천문학적 진실: 삭망월(Synodic Month)의 비정수성

문페이즈를 기계로 구현할 때 시계 제작자들이 마주하는 첫 번째 난관은, 달이 삭(New Moon)에서 망(Full Moon)을 거쳐 다시 삭으로 돌아오는 **1 삭망월(Synodic Month)**의 길이가 깔끔한 정수가 아니라는 사실입니다.

현대 정밀 천문 관측에 따른 평균 삭망월의 길이는 다음과 같습니다:

$$T_{\text{moon}} = 29.530588853 \text{ days} \quad (29\text{일 } 12\text{시간 } 44\text{분 } 2.8\text{초})$$

기계식 시계는 톱니바퀴의 정수 개 이빨(Tooth)로만 회전 비율을 나눌 수 있습니다. 톱니를 0.53개나 0.03개로 깎을 수는 없습니다. 시계 공학은 이 무리수에 가까운 소수점을 어떻게 정수 기어의 조합으로 근사(Approximation)해 냈을까요?

## 3. 표준 문페이즈: 59톱니 휠의 우아한 마법

가장 널리 사용되는 전통적인 문페이즈 디스크는 **59개의 톱니**를 가진 별바퀴(Star Wheel)입니다. 왜 하필 59일까요?

```
[시침 휠 (24시간에 1회전)] ──> [푸셔 핑거: 24시간마다 1회 톱니 밀침]
                                            │
                                            ▼
                    [59개 톱니를 가진 문페이즈 디스크 회전]
                    (디스크 표면에 2개의 보름달이 180° 대칭 인쇄)
```

1. **두 개의 달 인쇄:** 원형 디스크 표면에 180도 마주 보는 위치에 똑같은 모양의 금빛 달을 2개 인쇄합니다.
2. **2회 주기의 합:** 달이 한 번 차오르고 지는 데 약 29.5일이 걸리므로, 달이 2번 차오르고 지는 데 걸리는 시간은 정확히 $29.5 \times 2 = 59\text{일}$입니다!
3. **하루에 1칸 전진:** 시계의 시침 바퀴(24시간 기어)에 달린 작은 손가락(Finger)이 매일 밤 자정마다 59톱니 디스크를 정확히 '1톱니(1칸)'씩 밀어 넘깁니다.

결과적으로 1개의 달이 창을 지나가는 데 걸리는 시간은:

$$\frac{59\text{ teeth}}{2} = 29.500000 \text{ days} \quad (29\text{일 } 12\text{시간 } 00\text{분 } 00\text{초})$$

### 59톱니의 누적 오차:
실제 삭망월($29.530588$일)과 59톱니 기어($29.500000$일) 사이에는 매달 **약 44분 2.8초의 시차**가 발생합니다.
이 미세한 차이가 매달 누적되면, 대략 **2년 7개월(약 972일)이 지났을 때 문페이즈 디스크가 실제 밤하늘의 달 위상보다 정확히 하루(1일) 뒤처지게 됩니다.** 따라서 일반적인 문페이즈 시계는 3년에 한 번씩 케이스 측면의 핀홀을 눌러 하루치를 앞당겨 주어야 합니다.

## 4. 122년 오차의 하이엔드 문페이즈 (135톱니)

하이엔드 매뉴팩처(랑에 운트 죄네, 블랑팡, 파텍 필립 등)는 3년마다 생기는 1일의 오차를 용납하지 않았습니다.

그들은 59톱니 대신 중간 감속 휠 트레인과 **135개 톱니를 가진 정밀 문페이즈 휠**을 개발했습니다.
- 기어비: $T = 29.53085$일
- 실제 삭망월과의 오차는 하루에 단 57초에 불과합니다.
- 이 시계는 **122.6년 동안 시계를 멈추지 않고 계속 작동시켜도 누적 오차가 단 하루(1일)**밖에 발생하지 않습니다! 사람의 일생 동안 단 한 번도 조정할 필요가 없는 수준입니다.

더 나아가 랑에 운트 죄네의 '리차드 랑에 테라-루나'나 크리스티안 반 데어 클라우의 천문 시계는 여러 겹의 에피사이클릭(유성) 기어 트레인을 결합하여 **1,000년, 혹은 200만 년 동안 1일의 오차만 발생하는 궁극의 천문 문페이즈**를 탄생시키기도 했습니다.

## 5. 결론: 인간의 손목에서 숨 쉬는 은하계

우리가 일상에서 바라보는 시계 바늘이 인공적인 24시간 사회의 규율을 가리킨다면, 조용히 차오르고 기우는 문페이즈의 달은 지구와 달이 중력으로 맺어진 원초적인 대자연의 리듬을 속삭입니다.

단 59개, 혹은 135개의 작은 금속 톱니를 정교하게 깎아 맞추는 것만으로 수억 킬로미터 우주 너머 천체의 운행을 오차 없이 재현해 내는 문페이즈는 시계 공학이 천문학에 바치는 가장 시적(Poetic)이고 우아한 헌사입니다.
