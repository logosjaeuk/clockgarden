## 1. 노션이 복잡해서 결국 안 쓰게 되는 사람들을 위한 조언

노션을 열심히 꾸미다 보면 페이지가 수십 개로 늘어나고, "그 메모가 어느 하위 폴더에 있었지?", "오늘 해야 할 일이 어디 적혀 있었지?"를 찾아 헤매다가 결국 노션을 포기하는 경우가 많습니다.

생산성 전문가들이 공통적으로 추천하는 워크스페이스 원칙은 **"작업은 분산된 데이터베이스에서 처리하되, 하루의 시작과 끝은 오직 단 하나의 '홈 대시보드(Home Dashboard)'에서 이루어져야 한다"**는 것입니다.

출근하자마자 1초 만에 오늘의 우선순위를 파악하고, 불필요한 탭 전환 없이 딥워크(Deep Work)에 돌입할 수 있는 미니멀 올인원 대시보드 구축법을 공개합니다.

---

## 2. 대시보드 화면 분할 3단 레이아웃

가장 이상적인 대시보드 레이아웃은 시선의 자연스러운 흐름을 고려한 **좌측 네비게이션(1/3) + 우측 메인 실행 영역(2/3)** 구조입니다.

```
┌─────────────────────────┬──────────────────────────────────────┐
│  [좌측 사이드바: 30%]   │        [우측 메인 워크존: 70%]       │
│                         │                                      │
│  - 퀵 인박스 (Quick In)  │  🔥 오늘의 집중 태스크 (Today Focus)  │
│  - 주요 바로가기 링크    │  - 기한 오늘까지 / 마감 임박 항목   │
│  - 이번 주 핵심 KPI     │  - 드래그 앤 드롭 완료 체크          │
│  - 루틴 트래커 (습관)   │                                      │
│                         ├──────────────────────────────────────┤
│                         │  📅 이번 주 프로젝트 타임라인       │
│                         │  📚 최근 수집한 지식 및 북마크       │
└─────────────────────────┴──────────────────────────────────────┘
```

노션 본문에서 `/열 2개(2 columns)`를 입력하여 좌우 영역을 분할합니다.

---

## 3. 우측 메인 영역의 핵심: '오늘의 집중 태스크(Today Focus)' 뷰

많은 사람들이 태스크 DB 전체를 그냥 대시보드에 끌어다 놓고 수백 개의 할 일에 압도당합니다. 대시보드에는 **오직 오늘 끝내야 하는 일만** 보여야 합니다.

### 설정 방법:
1. 메인 영역에 `/링크된 데이터베이스 보기` ➔ `태스크 DB` 선택.
2. 뷰 형태: **[리스트(List)]** 또는 **[보드(Board)]**.
3. **고급 필터 규칙(Filter Rules) 설정:**
   - 조건 1: `상태` 가 `완료`가 아님 (AND)
   - 조건 2: `마감일` 이 `오늘 또는 그 이전(On or before today)` 이거나, `오늘의 할 일` 체크박스가 활성화됨.
4. **정렬(Sort) 규칙:**
   - 1차: `우선순위` 내림차순 (긴급 ➔ 보통 ➔ 낮음)
   - 2차: `마감일` 오름차순

이렇게 필터를 걸어두면 아침에 대시보드를 켰을 때 오늘 처리해야 할 핵심 과업 3~5개만 화면에 깔끔하게 떠오르며, 체크박스를 누르는 즉시 화면에서 사라져 강력한 성취감을 줍니다.

## 4. 좌측 사이드바의 핵심: '퀵 인박스(Quick Inbox)'

업무 중에 불현듯 떠오르는 아이디어나 급하게 들어온 요청을 바로 정리하려고 폴더를 찾아가면 집중의 흐름(Flow)이 완전히 깨집니다.

사이드바 최상단에 토글이나 한 줄짜리 인박스 DB를 배치하세요:
- 속성을 아무것도 지정하지 않고 오직 **'제목'만 적고 엔터**를 칩니다.
- 하루 일과가 끝나는 오후 5시 30분에 인박스를 열어, 모인 5~6개의 메모에 마감일과 프로젝트를 지정하고 인박스를 비웁니다(Inbox Zero).

## 5. 지식 아카이브와 PARA 아키텍처 연동

개인 지식 관리(PKM)에는 티아고 포르테(Tiago Forte)의 **PARA 모델**을 대시보드 하단에 접목하는 것이 가장 깔끔합니다:

1. **Projects (프로젝트):** 현재 진행 중인 마감 기한 있는 일
2. **Areas (책임 영역):** 건강, 재정, 사내 운영 등 지속적으로 관리하는 영역
3. **Resources (자료 보관소):** 유용한 아티클, 북마크, 템플릿, 코드 조각
4. **Archives (보관소):** 종료된 프로젝트와 더 이상 보지 않는 과거 문서

대시보드 하단에는 'Resources' 데이터베이스 중 최근 일주일간 스크랩한 아티클을 갤러리 뷰로 띄워두면 영감과 아이디어를 빠르게 되새길 수 있습니다.

---

## 6. 대시보드 유지의 황금률: '장식을 줄여라'

GIF 애니메이션이나 너무 큰 커버 이미지, 불필요한 날씨 위젯을 대시보드에 덕지덕지 붙여두면 페이지 로딩 속도가 3~5초 이상 느려집니다.

대시보드는 **'감상용 미술관'이 아니라 '초고속 출격 기지'**여야 합니다. 군더더기 없는 미니멀 텍스트와 정확한 필터 뷰만으로 채워진 대시보드가 여러분의 하루 업무 시간을 최소 30분 이상 절약해 줄 것입니다.
