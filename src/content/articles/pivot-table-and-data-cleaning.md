## 1. 피벗 테이블이 실패하는 이유는 기능이 아니라 '데이터 상태' 때문입니다

많은 실무자가 피벗 테이블(Pivot Table)을 만들 때 "합계가 이상하게 나온다", "날짜별 그룹화가 안 먹힌다", "열이 제멋대로 분할된다"며 답답함을 토로합니다.

하지만 이는 피벗 테이블 기능의 문제가 아니라, 피벗의 재료가 되는 **원본 데이터의 구조(Table Architecture)**가 비정규형(Unnormalized)으로 오염되어 있기 때문입니다.

데이터 분석의 세계에는 **"Garbage In, Garbage Out(쓰레기가 들어가면 쓰레기가 나온다)"**이라는 명언이 있습니다. 아무리 뛰어난 분석 도구를 쓰더라도 기본 재료가 정돈되지 않으면 신뢰할 수 있는 인사이트를 얻을 수 없습니다.

## 2. 피벗 테이블이 사랑하는 '올바른 원본 데이터 7원칙'

피벗 테이블을 삽입하기 전에 원본 테이블이 다음 7가지 조건을 만족하는지 반드시 확인해야 합니다:

1. **병합된 셀(Merge) 0개:** 머리글이든 본문이든 셀 병합은 피벗 테이블의 가장 큰 적입니다. 모든 셀 병합을 해제해야 합니다.
2. **단일 행 머리글:** 표의 제목이나 열 이름은 반드시 1개의 행으로 구성되어야 하며, 2단 머리글은 피해야 합니다.
3. **빈 행과 빈 열 제거:** 데이터 중간에 시각적 구분을 위해 삽입해 둔 빈 행이나 빈 열은 피벗 테이블의 범위를 끊어 놓습니다.
4. **하나의 열에는 하나의 데이터 타입만:** 숫자 열에 `"미정"`, `"없음"`, `"-"` 같은 텍스트가 섞여 있으면 전체 열이 문자로 인식되어 합계나 평균 계산이 불가능해집니다.
5. **날짜 데이터의 표준화:** 날짜는 반드시 실제 날짜 서식(`YYYY-MM-DD`)으로 기록되어야 하며, 텍스트 형태(`2026.11.02.`)로 입력되면 연도/월별 그룹화가 동작하지 않습니다.
6. **고유한 열 머리글 이름:** 모든 열은 비어 있지 않고 고유한 식별 이름을 가져야 합니다.
7. **가로형 데이터의 세로형(Flat) 전환:** 1월, 2월, 3월이 가로 열로 나열된 장부는 '월'이라는 단일 열에 세로로 쌓아야 올바른 피벗 분석이 가능합니다.

## 3. 실무 데이터 정제(Cleaning) 핵심 함수 3총사

더러운 원본 데이터를 깔끔하게 다듬을 때 가장 요긴하게 쓰이는 필수 함수 3가지입니다.

### ① 불필요한 공백 제거: `TRIM`
복사해 온 데이터 양 끝에 보이지 않는 공백이 있으면 `"서울"`과 `"서울 "`을 서로 다른 도시로 인식합니다.
```excel
=TRIM(A2)
```

### ② 텍스트로 저장된 숫자를 진짜 숫자로 변환: `VALUE` 또는 곱하기 1
ERP에서 내려받은 숫자가 문자로 인식되어 좌측 정렬되어 있다면:
```excel
=VALUE(B2)  또는  =B2 * 1
```

### ③ 날짜 텍스트를 정식 날짜 시리얼로 파싱: `DATE` + `MID`/`LEFT`
텍스트 `"20261102"`를 날짜로 바꿀 때:
```excel
=DATE(LEFT(A2, 4), MID(A2, 5, 2), RIGHT(A2, 2))
```

## 4. 피벗 테이블 실무 고급 기능

### 1) 날짜 자동 그룹화 (연/분기/월)
피벗 테이블의 날짜 열 셀에서 마우스 우클릭 ➔ **[그룹(Group)]**을 선택하면, 일 단위로 나열된 수만 건의 거래 데이터를 순식간에 **연도별**, **분기별**, **월별**로 계층 구조화할 수 있습니다.

### 2) 사용자 정의 '계산 필드(Calculated Field)' 활용
원본 데이터에 없는 파생 지표(예: `마진율 = (매출액 - 원가) / 매출액`)를 원본에 열을 추가하지 않고 피벗 테이블 내부에서 즉석 연산할 수 있습니다.

- 메뉴 경로: **[피벗 테이블 분석] ➔ [필드, 항목 및 집합] ➔ [계산 필드]**
- 수식 입력: `= (매출액 - 원가) / 매출액`
- 이름 설정: `마진율`

이렇게 생성된 계산 필드는 슬라이서로 지사를 필터링하거나 기간을 바꿀 때마다 동적으로 가중 평균 마진율을 정확하게 재계산합니다.

## 5. 실무 적용 팁: 슬라이서(Slicer)와 타임라인으로 대시보드 완성하기

피벗 테이블을 단독으로 두지 마시고, 상단 메뉴의 **[슬라이서 삽입]**과 **[시간 표시 막대 삽입]**을 활용해 보세요.

보고 대상자(팀장, 임원, 클라이언트)가 마우스 클릭 한 번으로 특정 부서나 특정 기간을 인터랙티브하게 필터링할 수 있는 멋진 미니 대시보드를 5분 만에 구축할 수 있습니다.

데이터 전처리의 기본기를 갖추는 것은 복잡한 수식을 외우는 것보다 훨씬 더 큰 실무적 생산성을 안겨줍니다.
