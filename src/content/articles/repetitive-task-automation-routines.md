## 1. "이걸 언제 손으로 다 바꾸고 있지?"라는 생각이 들 때가 바로 자동화의 순간입니다

매주 수십 개의 스크린샷 파일 이름을 하나하나 F2 눌러가며 날짜를 붙이고 있거나, 50장의 제품 사진 해상도를 포토샵에서 한 장씩 줄이고 있다면 여러분은 기계가 해야 할 일을 인간의 손으로 대신하고 있는 것입니다.

많은 사람들이 "업무 자동화"라고 하면 파이썬(Python) 프로그래밍이나 복잡한 매크로 코딩을 떠올리고 진입 장벽을 느낍니다.

하지만 우리가 매일 쓰는 Windows와 macOS에는 마이크로소프트와 애플이 공식적으로 무료 제공하는 놀라운 시스템 레벨 자동화 툴킷이 이미 탑재되어 있습니다:
- **Windows:** Microsoft PowerToys (파워토이)
- **macOS:** Apple 단축어 (Shortcuts) & Automator

코드 한 줄 몰라도 지금 당장 써먹을 수 있는 일상 업무 자동화 루틴 3가지를 소개합니다.

---

## 2. 자동화 루틴 ① 수백 개 파일 이름 3초 만에 일괄 변경하기

### 윈도우 사용자: 파워토이 'PowerRename'
마이크로소프트 공식 유틸리티인 PowerToys를 설치하면 탐색기 우클릭 메뉴에 **[PowerRename]**이 추가됩니다.
- 활용 예: `스크린샷_2026-11-05_1.png` 형태의 파일 50개를 `[프로젝트]_001.png` 형태로 정규식 기반 일괄 치환.
- 특정 단어 검색 및 바꾸기, 번호 자동 넘버링, 대소문자 변환이 실시간 미리보기를 보며 단 1초 만에 실행됩니다.

### 맥 사용자: 파인더 내장 '파일 이름 변경'
맥은 별도 프로그램 설치조차 필요 없습니다:
1. 파인더에서 파일 수십 개를 드래그 선택.
2. 우클릭 ➔ **[이름 변경(Rename...)]** 선택.
3. '텍스트 대치' 또는 '포맷(이름 및 카운터/색인)'을 선택해 접두사나 날짜를 일괄 부여하면 끝납니다.

## 3. 자동화 루틴 ② 매일 반복해서 치는 문장 0.5초 완성 (텍스트 대치)

사업자등록번호, 회사 기본 계좌번호, 안내 이메일 템플릿, 자주 쓰는 줌 회의실 링크를 매번 메모장에서 찾아 복사하고 계신가요?

### 텍스트 대치(Text Replacement) 세팅:
운영체제의 텍스트 대치 기능을 활성화해 두면 특정 단축어 입력 시 긴 문장으로 자동 변환됩니다.

| 내가 입력하는 단축어 | 자동으로 대치되는 완성 문장 |
| :--- | :--- |
| `;;계좌` | 국민은행 123-456-789012 (예금주: 주식회사 클락가든) |
| `;;사업자` | 123-45-67890 (대표: 홍길동 / 업태: 서비스) |
| `;;줌` | https://zoom.us/j/123456789 (비밀번호: 2026) |
| `;;인사` | 안녕하십니까, 클락가든 기획팀 김철수 대리입니다. 보내주신 메일 잘 받아보았습니다. |

> [!TIP]
> 일반적인 단어와 겹치지 않도록 앞에 세미콜론 2개(`;;`)나 슬래시(`//`)를 붙이는 규칙을 사용하면 일상 타이핑 중 오발동되는 현상을 완벽하게 방지할 수 있습니다.

## 4. 자동화 루틴 ③ 대용량 이미지 일괄 리사이징 & 웹 포맷 변환

블로그나 사내 보고서에 올릴 고해상도 사진 30장의 용량을 줄여야 할 때:

### 윈도우: 파워토이 'Image Resizer'
1. 사진 파일들을 선택 ➔ 우클릭 ➔ **[그림 크기 조정(Resize pictures)]**
2. 모바일(854×480), 데스크톱(1920×1080), 또는 사용자 정의 가로 1200px 설정.
3. [크기 조정]을 누르면 원본 손상 없이 5초 만에 최적화된 복사본이 생성됩니다.

### 맥: '빠른 동작(Quick Actions)' 생성
파인더에서 이미지 우클릭 ➔ **[빠른 동작] ➔ [이미지 변환]**을 누르면 JPG, PNG, HEIC 포맷 변환과 소/중/대 크기 압축이 즉시 처리됩니다.

## 5. 결론: 작은 자동화가 모여 1시간의 여유를 만듭니다

파일 이름 바꾸기 5분, 계좌번호 찾기 2분, 이미지 크기 줄이기 10분... 사소해 보이는 잡무들이 모여 하루의 1시간을 갉아먹습니다.

오늘 소개한 OS 내장 자동화 도구들을 한 번만 세팅해 두세요. 단순 반복 작업은 컴퓨터에게 떠넘기고, 여러분의 지성과 에너지는 진짜 중요한 기획과 통찰에 집중하세요.
